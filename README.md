## What I bring

- **Detection engineering:** Splunk rules written as code, mapped to MITRE ATT&CK and validated in CI.
- **Threat intelligence:** STIX / TAXII feeds turned into Splunk lookups, with expired indicators removed.
- **Purple teaming:** Atomic Red Team and CALDERA runs compared against detections, with a DETECTED / MISSED report.
- **Malware analysis:** static PE analysis, Ghidra and strace in isolated labs.
- **Automation:** Python, Bash and PowerShell tools that reduce repetitive SOC and IT work.
